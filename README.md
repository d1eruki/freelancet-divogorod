# Редизайн сайта «Дивогород»

Проект редизайна сайта семейного детского центра «Дивогород» в Санкт-Петербурге.

Текущий сайт: [дивогород.рф](https://xn--b1acbcr1bbar.xn--p1ai/)

## О проекте

«Дивогород» — семейный центр развития и образования детей. В одном пространстве центр объединяет:

- занятия с логопедом, дефектологом и нейропсихологом;
- диагностику и коррекцию речевых и нейропсихологических трудностей;
- детский сад с логопедическим сопровождением;
- семейное обучение по программе Русской Классической Школы;
- социализацию и адаптационные программы для детей с РАС;
- творческие, интеллектуальные и развивающие кружки.

Центр работает с семьями, которым нужна как коррекционная помощь, так и среда для повседневного развития, обучения и социализации ребёнка. Основная ценность «Дивогорода» — комплексный маршрут внутри одного центра: от первичной консультации и подбора специалиста до регулярных занятий, детского сада или семейного обучения.

Адрес центра: Санкт-Петербург, проспект Солидарности, дом 9, корпус 3.
